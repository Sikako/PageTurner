## 5 分鐘快速開始

### 第一次使用

```
┌─────────────────────────────────────┐
│   1. 安裝應用程式                    │
│   ↓                                 │
│   2. 開啟應用並授予權限              │
│   ↓                                 │
│   3. 在閱讀器上搜尋並連接手機        │
│   ↓                                 │
│   4. 在應用中啟用該裝置              │
│   ↓                                 │
│   5. 開始翻頁！                      │
└─────────────────────────────────────┘
```

### 步驟 1: 安裝應用程式

**從 APK 安裝**（開發版本）：
```bash
npm install
npm run android
```

**從 Play Store 安裝**（未來發布時）：
- 搜尋 "PageTurner"
- 點擊安裝

### 步驟 2: 開啟應用並授予權限

1. 開啟 PageTurner
2. 允許藍牙廣播權限
3. 允許藍牙連接權限
4. （Android 11- 需要）允許位置權限

![權限請求範例]

### 步驟 3: 連接閱讀器

1. 在您的電子書閱讀器上：
   - 開啟設定 → 藍牙
   - 搜尋藍牙裝置
   - 找到您的手機名稱（例如 "Pixel 7"）
   - 點擊連接

2. 等待配對完成

### 步驟 4: 啟用控制

1. 在 PageTurner 應用中，「已連線的裝置」列表會出現您的閱讀器
2. 點擊閱讀器旁邊的「啟用控制」按鈕
3. 看到「目標已設定」提示

### 步驟 5: 開始翻頁

**方法 A：手動控制**
- 在控制面板中點擊「下一頁」或「上一頁」按鈕

**方法 B：音量鍵控制**（需要額外設定）
- 點擊「啟用音量鍵控制」
- 使用音量鍵：
  - 音量加 = 下一頁
  - 音量減 = 上一頁

恭喜！您已經完成設定！ 🎉

## 詳細設定步驟

### 手機設定

#### 檢查藍牙功能

確保您的手機：
- 執行 Android 8.0 或更高版本
- 支援 Bluetooth 5.0 和 BLE
- 支援 HID over GATT（大多數現代手機都支援）

檢查方法：
```bash
adb shell getprop ro.build.version.sdk
# 應該 >= 26 (Android 8.0)

adb shell pm list features | grep bluetooth
# 應該包含 android.hardware.bluetooth_le
```

#### 優化電池設定

為確保背景運行，建議進行以下設定：

**小米/紅米**：
1. 設定 → 應用程式 → 管理應用程式 → PageTurner
2. 電池省電 → 無限制
3. 自啟動 → 允許
4. 鎖定最近使用中的應用

**華為**：
1. 設定 → 電池 → 應用程式耗電管理 → PageTurner → 允許
2. 設定 → 應用程式 → 應用程式啟動管理 → PageTurner
3. 關閉自動管理，手動允許自啟動、關聯啟動、背景活動

**OPPO/Realme**：
1. 設定 → 電池 → 省電模式設定 → PageTurner → 允許背景執行
2. 最近使用中鎖定 PageTurner

**原生 Android**：
1. 設定 → 應用程式 → PageTurner → 電池
2. 電池優化 → 所有應用程式 → PageTurner → 不優化

### 閱讀器設定

#### 支援的閱讀器

**已測試**：
- bigme b751c ✅

**理論上支援**（未測試）：
- 任何支援 HID over GATT 的電子書閱讀器
- 支援藍牙鍵盤輸入的閱讀器

#### 連接步驟（bigme b751c 範例）

1. **開啟藍牙**
   - 設定 → 無線與網路 → 藍牙 → 開啟

2. **搜尋裝置**
   - 點擊「搜尋裝置」
   - 等待掃描完成

3. **配對**
   - 找到您的手機
   - 點擊配對
   - 如果要求 PIN 碼，輸入 "0000" 或 "1234"

4. **驗證連接**
   - 在 PageTurner 應用中查看裝置列表
   - 應該會看到閱讀器已連接

## 常用操作

### 連接新的閱讀器

1. 確保目前沒有其他閱讀器正在控制中
2. 在新閱讀器上搜尋並連接手機
3. 在裝置列表中啟用新閱讀器

### 切換目標閱讀器

1. 點擊當前閱讀器的「斷開連接」（這不會中斷藍牙，只是取消目標）
2. 點擊新閱讀器的「啟用控制」

### 使用音量鍵控制

1. 確保已選擇目標裝置
2. 點擊「啟用音量鍵控制」按鈕
3. 現在音量鍵將控制翻頁而非音量
4. 要恢復音量功能，點擊「停用音量鍵控制」

**提示**：
- 音量鍵控制在螢幕關閉時仍然有效
- 適合單手閱讀時使用

### 查看日誌

1. 切換到「日誌」標籤
2. 選擇要查看的日誌等級
3. 滾動查看所有記錄

**使用場景**：
- 確認連接是否成功
- 確認翻頁指令是否發送
- 除錯問題

### 匯出日誌

1. 在日誌頁面點擊分享圖示
2. 選擇分享方式（Gmail、Telegram 等）
3. 發送或儲存日誌

**用途**：
- 回報問題時附上日誌
- 分析使用模式

### 清除日誌

1. 在日誌頁面點擊刪除圖示
2. 確認清除
3. 所有日誌將被刪除

**建議時機**：
- 日誌累積太多影響效能
- 重新開始測試前
- 隱私考量

### 背景運行

1. 按下 Home 鍵將應用放到背景
2. 通知欄會顯示「PageTurner 正在運行」
3. 藍牙連接和控制功能繼續運作

**注意**：
- 不要從最近使用清單中滑掉應用
- 不要使用清理工具清理應用
- 參考「手機設定」章節優化電池設定

## 最佳實踐

### 日常使用

#### 開始閱讀前

```
1. 開啟 PageTurner 應用
   ↓
2. 確認狀態列顯示閱讀器已連接
   ↓
3. 啟用音量鍵控制（如果需要）
   ↓
4. 按 Home 鍵切換到閱讀器應用
   ↓
5. 開始閱讀和翻頁
```

#### 閱讀完成後

```
1. 停用音量鍵控制（恢復音量功能）
   ↓
2. 可選：取消目標裝置
   ↓
3. 可選：關閉應用（停止前台服務）
```

### 多裝置管理

如果您有多個閱讀器：

1. **命名規則**
   - 在閱讀器設定中給每個裝置有意義的名稱
   - 例如：「臥室閱讀器」、「客廳閱讀器」

2. **快速切換**
   - 保持多個閱讀器同時連接
   - 需要時快速切換目標
   - 無需重新配對

3. **連接管理**
   - 定期檢查連接列表
   - 移除不再使用的裝置

### 效能優化

#### 減少電池消耗

1. **不使用時**：
   - 停用音量鍵控制
   - 取消目標裝置
   - 關閉應用

2. **長時間閱讀**：
   - 使用手動翻頁而非音量鍵
   - 降低螢幕亮度
   - 開啟省電模式（確保 PageTurner 在白名單）

#### 保持穩定連接

1. **環境**：
   - 避免金屬障礙物
   - 遠離 WiFi 路由器、微波爐
   - 保持 5 米內距離

2. **裝置**：
   - 保持手機和閱讀器電量充足
   - 定期重新啟動藍牙

### 故障預防

#### 定期維護

**每週**：
- 檢查應用更新
- 清除累積的日誌

**每月**：
- 清理不需要的藍牙配對
- 檢查電池使用情況

#### 備份設定

目前應用不儲存設定，但記下：
- 常用的閱讀器名稱
- 閱讀器的藍牙地址

### 安全建議

1. **隱私**：
   - 日誌可能包含裝置名稱和地址
   - 分享日誌前檢查內容

2. **連接**：
   - 只連接您信任的閱讀器
   - 不要在公共場所開啟廣播（理論上他人也能連接）

3. **權限**：
   - 只授予必要權限
   - 定期檢查權限使用

## 進階技巧

### 自訂按鍵（需要修改程式碼）

修改 `MainScreen.tsx`：
```typescript
const handlePageTurn = useCallback(async (direction: 'left' | 'right') => {
  // 修改這裡的按鍵碼
  const keyCode = direction === 'left' ? 0x50 : 0x4F;
  
  // 可以改為：
  // Page Up/Down
  // const keyCode = direction === 'left' ? 0x4B : 0x4E;
  
  await HIDPeripheralService.sendKeyPress(keyCode);
}, [targetDevice]);
```

### 監控連接品質

使用 adb 即時監控：
```bash
adb logcat -v time | grep -E "connected|disconnected"
```

### 自動化測試

建立測試腳本：
```bash
#!/bin/bash
# test-connection.sh

echo "Testing PageTurner connection..."

# 檢查應用是否運行
if adb shell ps | grep -q com.pageturner; then
    echo "✓ App is running"
else
    echo "✗ App is not running"
    exit 1
fi

# 檢查服務
if adb shell dumpsys activity services | grep -q ForegroundService; then
    echo "✓ Foreground service is active"
else
    echo "✗ Foreground service is not active"
    exit 1
fi

echo "All checks passed!"
```

## 常見問題速查

| 問題 | 快速解決 |
|------|---------|
| 閱讀器找不到手機 | 檢查藍牙是否開啟，重啟應用 |
| 連接後立即斷線 | 縮短距離，重新配對 |
| 無法翻頁 | 確認已啟用目標裝置 |
| 音量鍵不工作 | 確認已啟用音量鍵控制 |
| 背景停止運作 | 關閉電池優化，鎖定應用 |
| 應用閃退 | 查看日誌，回報問題 |
